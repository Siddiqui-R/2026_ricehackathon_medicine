# Synthetic mixed PDF regression

Run `python3 scripts/check_document_import.py` on macOS with Xcode. It compiles the production import service and uses real PDFKit and Vision locally. The harness generates an embedded fax header above an image containing fictional dose and negation text, checks the image body was extracted, verifies original page mapping, checks complete-line numeric disagreement handling, and verifies that a late low-text scan retains one of the ten OCR slots after ten graphical headers while skipped pages keep their embedded text and review warning. It does not test physical iPhone behavior or guarantee OCR accuracy for other documents.

`mixed-content.pdf` is the same two-page synthetic fixture, generated by `Check.swift`. The first page embeds only a long header; its body is an image. The second page contains ordinary embedded text. Passing an output path to the compiled harness regenerates the fixture. The browser's `extractDocument.test.ts` uses actual PDF.js parsing/rendering of this file and a controlled OCR response to test the extraction branches and failure behavior without a worker/network dependency.
